# REIS CASH

Controle pessoal de contas e dívidas, em azul pastel, adaptado para celular e computador.

## Usar

Abra https://amcreis.github.io/REIS-CASH/ depois da publicação pelo GitHub Pages.

Cadastre descrição, categoria, valor total, vencimento e pagamento à vista ou parcelado. As parcelas são distribuídas pelos meses, respeitando o último dia de cada mês e mantendo a soma exata dos centavos. Clique no status para registrar ou desfazer um pagamento. A edição e exclusão afetam a compra inteira.

## Dados

Os registros ficam no armazenamento local do navegador, sem conta de usuário ou sincronização. Limpar os dados do navegador pode apagar os registros. Exporte backups regularmente e guarde-os em local privado. Restaurar um backup substitui os registros atuais. Não envie backups ao repositório público.

## Publicação

Em Settings → Pages, escolha Deploy from a branch, branch main e pasta / (root). Salve e aguarde a publicação. O endereço será https://amcreis.github.io/REIS-CASH/.

## Arquivos

Site estático, sem dependências: index.html e app.js. Não requer servidor de banco de dados nem instalação de pacotes.
